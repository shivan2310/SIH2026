## ✨ Features

- 🏗️ **Interactive Circuit Lab**: A visual, drag-and-drop builder with a synced two-way code editor.
- ⚡ **Local Zero-Cost Simulation**: Runs entirely in-browser using a pure-TypeScript statevector engine (no server or queue required!).
- 📊 **State Visualization**: Live Bloch spheres, probability histograms, and phase tables that update instantly.
- 🧠 **Intelligent Tutoring**: AI assistance using local models (like Ollama) to help you learn and debug.
- 🌍 **Multi-Backend Support**: Dispatch your circuits to IBM Quantum, qBraid, or local open-source Python servers.

## 🚀 Getting Started

Ensure you have [Bun](https://bun.sh/) or [Node.js](https://nodejs.org/) installed on your machine.

### Installation

```bash
# Using Bun (Recommended)
bun install

# Using npm
npm install
```

### Running the Development Server

```bash
# Using Bun
bun run dev

# Using npm
npm run dev
```

Navigate to `http://localhost:5173` to explore the lab.

## 🛠️ Built With

This project relies on a highly-optimized, modern web stack:
- **Framework:** [TanStack Start](https://tanstack.com/start) based on [TanStack Router](https://tanstack.com/router)
- **UI & Styling:** [Tailwind CSS v4](https://tailwindcss.com/) & [Shadcn UI](https://ui.shadcn.com/) (Radix Primitives)
- **State & Data:** [TanStack Query](https://tanstack.com/query)
- **Backend & Database:** [Supabase](https://supabase.com/) & [better-sqlite3](https://github.com/WiseLibs/better-sqlite3)
