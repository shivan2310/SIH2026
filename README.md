# QuantumLab

An interactive, AI-powered web platform for learning, designing, simulating, and visualizing quantum algorithms.

## Features

- **Interactive Circuit Lab**: Drag-and-drop builder and synced code editor.
- **Local Zero-Cost Simulation**: Runs in-browser using a statevector engine.
- **Intelligent Tutoring**: AI assistance using local models (like Ollama).
- **Multi-Backend**: Supports IBM Quantum, qBraid, and local open-source Python servers.

## Development

You need Node.js and npm (or Bun) installed.

```sh
npm install
npm run dev
```
